# Scoot Nha Trang

Демо сервиса аренды скутеров в Нячанге. Первый парк — Honda Lead 125, годы выпуска 2012–2020. Клиент работает в браузере и Telegram WebView; отдельная API-служба пока предоставляет только health check.

## Что уже работает

- Главная страница с промо-изображением и базовым брендингом Scoot Nha Trang.
- `/admin` — три раздела: сводка поездок и парка, список скутеров, интерактивная карта.
- На карте можно фильтровать парк по статусу и уровню топлива, выбирать байки, рисовать и включать/выключать зоны запрета парковки.
- В демо завершение поездки блокируется, если точка скутера находится внутри активной зоны. Тестовая попытка проверяется из сводки.
- Карта Google Maps подключается по `VITE_GOOGLE_MAPS_API_KEY`; без ключа доступна интерактивная схематичная карта района.
- Список, показатели скутеров и запретные зоны сохраняются в `localStorage` текущего браузера.

Данные парка, поездок и координаты вымышленные. Демо-правило зоны не отправляет команды на скутер. В реальной версии расположение должно поступать от GPS/телематики, а запрет завершения должен проверяться сервером и передаваться только через совместимое устройство/API.

## Подготовка к запуску

- `apps/web` — отдельное приложение фронтенда; GitHub Actions собирает его в GitHub Pages после push в `main`.
- API готовится как Docker-образ в GitHub Container Registry и может разворачиваться на DigitalOcean Droplet.
- Добавлена базовая схема Prisma для скутеров, поездок, парковочных зон, контентных страниц, объявлений и платных топ-размещений.
- Для контентных страниц подготовлен Tiptap; HTML нужно очищать на API перед сохранением/публикацией.

Демо-парк по-прежнему хранится в `localStorage`. Схема и Prisma-сервис — инфраструктурная основа, API CRUD, авторизация, телематика и интеграция команд со скутерами ещё не реализованы. Геозону должен проверять сервер перед завершением поездки; одной блокировки в браузере недостаточно.

## Запуск

Требуются Node.js 24.15+ и pnpm 11.25+.

~~~sh
pnpm install
cp apps/web/.env.example apps/web/.env.local
cp apps/api/.env.example apps/api/.env
pnpm --filter @bike-sharing/api db:generate
pnpm --filter @bike-sharing/api db:migrate:dev
pnpm dev
~~~

Перед миграцией укажите в `apps/api/.env` доступный PostgreSQL URL для отдельной dev-базы. Без рабочего `DATABASE_URL` API не запустится.

Клиент: http://localhost:5173

Админ-панель: http://localhost:5173/admin

Проверка API: http://localhost:3001/api/v1/health

`pnpm build` собирает обе части, `pnpm typecheck` проверяет типы.

Инструкции по GitHub Pages и DigitalOcean находятся в [docs/deployment.md](docs/deployment.md). Prisma-команды доступны в `apps/api`: `db:generate`, `db:migrate:dev`, `db:migrate:deploy`. Не запускайте миграции на существующей базе до согласования отдельной базы/пользователя и правил доступа.

## Структура

- `apps/web` — React + Vite, пользовательская страница и демо-админка.
- `apps/web/dist` — сохранённая в Git production-сборка Telegram Mini App; пересобирается локально или workflow GitHub Pages.
- `apps/api` — NestJS REST API, сейчас только health endpoint.
- `deploy/digitalocean` — контейнерная конфигурация API и reverse proxy с HTTPS.
- `.github/workflows` — отдельные workflow фронтенда и API.
- `docs/architecture.md` — архитектурные решения и известные ограничения.
- `docs/product.md` — функциональный объём текущего демо и следующий этап.

Для Google Maps создайте ограниченный по доменам ключ Maps JavaScript API и укажите его в `apps/web/.env.local` как `VITE_GOOGLE_MAPS_API_KEY`. Не коммитьте настоящий ключ.

Локальные env-файлы содержат безопасные заглушки. Не добавляйте реальные ключи и пароли в репозиторий.
