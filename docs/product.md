# Продуктовый объём демо

## Продукт

Scoot Nha Trang — задуманный сервис аренды скутеров в Нячанге. Первый парк планируется на Honda Lead 125 годов выпуска 2012–2020. Сейчас репозиторий содержит стартовый клиент и демонстрацию интерфейса, а не работающий сервис проката.

## Пользовательская страница

- Показывает бренд, сценарий аренды и пилотную модель скутера.
- Кнопка бронирования пока не активна.
- Страница рассчитана на обычный браузер и Telegram WebView.

## Демо-админка `/admin`

- Разделы `Обзор`, `Скутеры`, `Карта`.
- Сводка: байки в поездке/на стоянке/сервисе, поездки и километры за день, отклонённые поездки, технические сигналы и простои с переходом на карту.
- Список: поиск и фильтры по состоянию и топливу; карточка содержит ID, госномер, год, координаты, топливо, GPS-сигнал, длительность простоя и заметку.
- Карта: маркеры по статусу, фильтры по статусу и топливу, редактор полигональных зон парковки.
- Демо проверяет точку завершения активной поездки. Внутри активной зоны поездка не завершается, и интерфейс показывает причину.
- Google Maps подключается через `VITE_GOOGLE_MAPS_API_KEY`. Без ключа используется схематичная интерактивная карта района.
- Парк и геозоны хранятся в `localStorage`; поездки и показатели — демонстрационные.

Доступ к демо-админке не защищён. Клиентская проверка геозоны иллюстрирует требуемое поведение и может быть обойдена. Никакие команды на скутер не отправляются. Демо-данные нельзя считать реальным состоянием парка или использовать для выдачи техники.

## Планируемые разделы админки контента

- Редактор главной страницы и контентных страниц на Tiptap.
- Настройка витрин Top-5 по категориям: продажа скутеров, аренда скутеров и аренда жилья.
- Список платных размещений: топ жилья и продвижение объявлений о продаже скутеров, со сроком и состоянием подписки.

Для этих функций подготовлены зависимости Tiptap и начальные модели Prisma (`ContentPage`, `HomePageSettings`, `Listing`, `Subscription`, `TopPlacement`). Интерфейс и API управления ими ещё нужно реализовать. HTML редактора нельзя публиковать без серверной очистки.

## Следующий этап до операционной админки

1. Поднять API на моделях Prisma и подключить отдельную базу PostgreSQL; сохранить статусы, поездки, координаты и решения геозоны с временем и источником.
2. Добавить аутентификацию и роли до подключения реальных данных.
3. Реализовать API и интерфейсы управления контентом, Top-5 блоками и платными размещениями.
4. Подключить ограниченный по доменам ключ Google Maps; проверить затраты и лимиты перед запуском.
5. Подтвердить GPS/телематику для выбранных годов Honda Lead и безопасный API для запрета закрытия аренды.
6. Перенести проверку геозон на сервер. При завершении аренды сервер проверяет координаты, отказывает внутри зоны, сообщает клиенту причину и сохраняет отклонённую попытку.
7. Сверить значения дашборда с журналом событий и временем Вьетнама; затем подключать оплаты и операционный процесс выдачи/возврата.

## Открытые продуктовые вопросы

- Клиентский сегмент и основной язык интерфейса: туристы, местные жители или оба сегмента.
- Тарифы, длительность аренды, залог, топливо и правила выдачи/возврата.
- Как оператор подтверждает состояние, документы, шлемы, пробег и доступность скутера.
- Какие права и страховые проверки обязательны перед арендой 125 cc.
- Нужны ли свободная парковка по городу или выдача/возврат только в партнёрских точках.
- Есть ли одобренная телематика для выбранных годов Honda Lead.


## Визуальная тема и карточки сценариев

Пользовательская палитра строится вокруг тёплого песочного фона, пальмового зелёного и мягкого кораллового акцента с солнечным золотом для небольших деталей. В Telegram Mini App поверхности, основной текст и кнопки берут цвета из themeParams; обработчик themeChanged обновляет тему без перезапуска. В обычном браузере используются те же брендовые токены и системная тёмная тема как резерв.

Для стартовой страницы добавлены три авторские иллюстративные карточки-сценария: поездка по набережной, городской маршрут к кафе и поездка на смотровую площадку. Они помогают выбрать настроение, но не выдают эти места за проверенные маршруты или реальные точки свободных байков. Карта и разрешение геолокации остаются отдельным следующим шагом пилота.

Визуальный приём плиток вдохновлён каталогом режимов и подборок GetLive: фото первым объясняет содержание, короткий ярлык и заголовок сохраняют читаемость при быстром просмотре. Используем только собственные изображения и тексты. Источник референса: [GetLive](https://www.get-live.net/).
